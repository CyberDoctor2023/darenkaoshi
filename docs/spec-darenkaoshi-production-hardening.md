# 《大人考试》生产级加固

## Goal

在不改变题库、答题算法、视觉风格或用户已确认的音乐策略前提下，补齐真实访问中的状态竞态、数据加载超时、移动端场景导航收尾和静态资源缓存边界，降低用户误跳场景、页面长期等待和旧资源错配的风险。

## Non-goals

- 不改变答题顺序、结果计算、结果卡牌内容或路由信息架构。
- 不新增场景音效、选项音效或第二段背景音乐。
- 不运行测试；测试由用户执行。
- 不引入新的第三方运行时或部署平台。

## Completion conditions

- 场景导航在 pointerleave/lostpointercapture 等收尾路径下仍能抑制拖动产生的合成点击。
- 用户在答案过渡动画期间切换首页或场景时，旧的延迟回调不会再次改写新状态。
- 游戏数据请求有明确超时与取消路径，失败页不会无限等待。
- 不可变的场景线稿与音频资源使用明确的长缓存策略，题库数据继续可重新验证。
- 入口引用在代码变更后递增资源版本参数，避免边缘缓存继续提供旧的应用脚本。
- Advanced Mode Worker 对静态资源响应统一补齐安全头与关键路径缓存头，避免只依赖 `_headers` 的执行边界差异。
- 发布包、Worker 路由与版本化入口资源完成静态检查并成功部署到 Cloudflare Pages；不运行测试。

## Validation plan

- `git diff --check`、JavaScript/JSON 静态检查与关键路径源码复核。
- 使用 `wrangler pages deploy deploy/darenkaoshi --project-name=cyberdoctor` 发布。
- 读取部署后的 `/`、`/darenkaoshi/`、`/doctor/` 响应头与入口内容，确认路由和缓存边界。
- 不执行项目测试或浏览器自动化测试。
