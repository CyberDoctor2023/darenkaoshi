# 《大人考试》声音策略

## Goal

当前版本只保留一段安静、专注、带考试氛围的持续循环长背景音乐；从对外入口首页 `/doctor/` 开始，覆盖答卷 `/` 的全部场景、切换和结果页。

## Non-goals

- 不加入场景专属背景音乐、选项点击音或语音旁白；所有答题场景共用同一段长背景音乐。
- 不改变答题顺序、计分、结果卡和已有视觉结构。
- 不绕过浏览器自动播放限制；入口页加载时立即预加载并尝试播放，被浏览器拦截时在首次互动中恢复。

## Decision

- 不加载音效库、不创建 Web Audio 上下文、不创建短音效。
- 只保留入口与答卷共用的长背景音乐；删除场景/选项音频素材与配置。音乐素材应是长段、克制、适合考试等待场景的开放授权录音。

## Completion conditions

- `/doctor/` 等待状态有一段持续循环的长背景音乐；页面加载时预加载并尝试自动播放，若被浏览器拦截则用户首次交互后立即播放。
- 进入答题、场景切换和结果卡后音乐保持循环，不切换、不停止；页面跳转时尽量从上一次播放位置继续。
- `/doctor/` 恢复原有手绘入口版式；音乐控制沿用入口页已有的控制，不在答卷页新增控制。

## Validation plan

- 检查代码与发布目录，确认入口页和答卷页共用同一段长背景音乐，没有场景/选项音频调用。
- 打开网页确认从路由页进入答题后音乐保持循环，场景切换和结果卡不触发换曲或停止。
