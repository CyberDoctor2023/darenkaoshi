# 《大人考试》音效体验

## Goal

为父母卷加入轻松、手绘游戏感的声音层：首屏等待时播放连续的游戏菜单背景音乐，进入答卷后播放连续的场景背景音乐，所有选项点击使用同一个统一的确认音，并提供可见的静音/开启控制。

## Non-goals

- 不加入语音旁白或强刺激的战斗音效。
- 不改变答题顺序、计分、结果卡和已有视觉结构。
- 不在首屏加载时绕过浏览器自动播放限制；声音应在用户首次点击后启动。

## Open-source choice

- 选项点击音使用 `jsfxr@1.4.1` 的统一 `blipSelect` 预设，来源：<https://github.com/chr15m/jsfxr>，仓库标注 Unlicense。
- 连续背景音乐选用 OpenGameArt 的 CC0 长音乐/循环素材：`Happy Clappy Loop`（首页等待）、`Calm Track`（家庭/日常）、`Sunset Walk`（轻快场景）、`Heavenly Loop`（梦想/天使）、`Contemplation`（告别/现实压力）。来源页面与作者信息记录在 `assets/audio/README.md`。
- 背景音乐以本地 `<audio loop>` 播放并在场景切换时淡入淡出，不把短音效拼接成背景音乐。

## Completion conditions

- 首页等待状态有持续循环的菜单音乐；用户首次交互后开始播放。
- 10 个场景均有数据驱动的连续背景音乐配置，允许多个场景复用同一首长音乐。
- 所有选项点击使用同一套轻量确认音，不按场景改变音色。
- 静音按钮在首页和答题页均可见，状态有 `aria-pressed` 和文本提示。
- 浏览器不支持 Web Audio 或用户关闭声音时，页面仍可完整答题。
- `prefers-reduced-motion` 不影响声音可用性；静音选择保存在本地；场景切换不产生短音拼接。

## Validation plan

- JSON 解析校验音效配置覆盖 10 个场景且无重复场景 ID，所有音频文件路径存在。
- 打开本地静态服务器，确认首页等待音乐、统一选项点击音、场景连续背景音乐和静音按钮行为。
- 检查 Git diff，确认只包含音效配置、运行时逻辑、样式、音频素材和许可证说明。
