# 《大人考试》声音策略

## Goal

当前版本只保留对外入口首页 `/doctor/` 等待时的一段安静、专注、带考试氛围的持续循环长背景音乐；从路由页进入答卷 `/` 后完全静音。

## Non-goals

- 不加入场景背景音乐、选项点击音或语音旁白。
- 不改变答题顺序、计分、结果卡和已有视觉结构。
- 不绕过浏览器自动播放限制；入口页加载时立即预加载并尝试播放，被浏览器拦截时在首次互动中恢复。

## Decision

- 不加载音效库、不创建 Web Audio 上下文、不创建短音效。
- 只保留首页等待音乐及其静音开关；删除场景/选项音频素材与配置。音乐素材应是长段、克制、适合考试等待场景的开放授权录音。

## Completion conditions

- `/doctor/` 等待状态有一段持续循环的长背景音乐；页面加载时预加载并尝试自动播放，若被浏览器拦截则用户首次交互后立即播放。
- 进入答题、场景切换和结果卡后不再播放任何声音。
- 声音开关只出现在 `/doctor/`，答题页不显示声音控制。

## Validation plan

- 检查代码与发布目录，确认只有 `/doctor/` 长背景音乐及其控制，没有答卷页音频调用。
- 打开网页确认从路由页进入答题后背景音乐停止，视觉交互不依赖声音。
