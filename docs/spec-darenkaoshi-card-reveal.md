# 《大人考试》结果卡牌 3D 弹出

## Goal

把结果页的身份卡从页面下方的独立详情区，改成结果生成后从纸面底部浮出的 3D 卡牌堆。卡牌以拟物化厚度、阴影、轻微倾斜和弹出动画表达“抽到后来”，点击卡牌后在当前结果区域上方展开详情。

## Non-goals

- 不改变身份卡数据、结果统计、成长/遗憾/幻想分类或重新答卷流程。
- 不保留页面下方的下拉选择器和独立详情列表作为主要交互。
- 不增加新的结果类型或重新计算结果。

## Completion conditions

- 结果页进入后，卡牌从结果区域底部向上弹出，并保留可见的卡牌厚度、纸张阴影和轻微 3D 倾斜。
- 结果卡牌堆位于结果标题附近，不再作为页面底部的独立列表区。
- 点击 3D 卡牌或对应的卡牌索引按钮，在当前结果区域打开拟物化详情浮层；关闭后回到卡牌堆。
- 详情浮层保留现有身份卡事实、场景线稿和幻想/现实标签。
- WebGL 不可用时仍显示可操作的卡牌索引和详情，不阻塞结果页。
- `prefers-reduced-motion` 下取消弹出动画，但保留卡牌与详情可见性。

## Validation plan

- 打开真实结果页，确认卡牌不再出现在页面下方的独立详情区域。
- 确认进入结果页时卡牌有从下向上的弹出和厚度阴影，点击卡牌后详情浮层在当前区域出现。
- 确认关闭详情后仍可选择其他卡牌，移动端没有横向溢出。
