# 《大人考试》选项顺序随机化

## Goal

每次新答卷开始时，为十个场景生成稳定的选项展示顺序，避免正向/预期选项长期固定在同一个字母位置；提交答案时仍使用原始选项索引，保证分支、身份卡、父母类型和结果计算不变。

## Non-goals

- 不改变任何选项文案、题库内容、分支规则或结果权重。
- 不引入单独的“标准答案”判定；这是反思式答卷，选项仍代表不同处理方式。
- 不运行测试；测试由用户执行。

## Completion conditions

- 新答卷为每个场景生成并保存一个完整的选项排列，展示字母按排列后的顺序重新标记。
- 答案事件、本地存档和结果页继续以原始选项索引读取分支。
- 旧版本本地存档可以继续恢复；没有排列记录时自动生成并保存新的排列。
- 选项顺序改动完成本地 Git 提交，并推送到 GitHub `main` 与 Cloudflare Pages 生产分支。

## Validation plan

- 静态检查 JavaScript 与 JSON 结构，复核展示索引和原始索引的转换链路。
- 检查 GitHub `main` 与本地提交一致，并发布到 Cloudflare Pages `main`。
- 不执行项目测试或浏览器自动化测试。
